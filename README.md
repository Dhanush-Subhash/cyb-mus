# cyb-mus

cyb-mus is a cyber-themed Android music player designed for focused listening and late-night sessions. It provides a clean, responsive interface for organizing local music, creating playlists, customizing sound, and controlling playback.

## Features

- Scans only user-selected music folders
- Supports MP3, FLAC, M4A, OGG, WAV, AAC, Opus, WebM, and AMR
- Searchable music library with responsive grid layout
- Displays song duration, file size, and audio format
- Album artwork support
- Playlist creation, editing, playback, and song reordering
- Play, pause, next, previous, seek, shuffle, and repeat controls
- Sleep timer with 5, 10, 15, 20, 25, and 30-minute options
- Scrollable custom equalizer
- Built-in EQ presets
- Save and delete custom EQ presets
- Nine-dot playback visualizer
- Custom wallpaper support with automatic theme colors
- Responsive UI scaling for different screen sizes
- Cyber-style interface with cherry blossom decoration
- Settings persist across app restarts

Built with Kotlin, Jetpack Compose, Media3, and Android’s audio APIs.
