# cyb-mus

cyb-mus is a cyber-themed Android music player designed for focused listening and late-night sessions. It provides a clean, responsive interface for organizing local music, creating playlists, customizing sound, and controlling playback.

### Features

- Scans your music library, with an option to select specific music folders
- Plays local audio files, including MP3, FLAC, M4A, OGG, WAV, AAC, OPUS, and other supported formats
- Searches songs by title, artist, or file type
- Displays album art, with bundled fallback covers for songs without artwork
- Lets you choose a custom photo cover for an individual song by long-pressing its cover in the library
- Creates and manages playlists, including selecting multiple songs to add or remove
- Reorders songs within playlists and plays a playlist
- Includes shuffle, repeat, sleep timer, and playback controls
- Provides a nine-band equalizer with built-in and saveable custom presets
- Lets you choose a wallpaper and adjust its blur and opacity; the wallpaper appears across app sections
- Adapts the interface to fit different screen sizes

cyb-mus plays music stored on your device; it does not currently stream or download music online.

Built with Kotlin, Jetpack Compose, Media3, and Android’s audio APIs.
